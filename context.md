# Contexto del Proyecto

## Nombre del Proyecto
**Vibe Check IA: Analizador de Sentimientos en Twitter**

## Problema

Las redes sociales generan millones de publicaciones cada día. Detrás de cada tweet hay una emoción: alegría, enojo, tristeza, sorpresa o indiferencia. Entender qué sienten las personas en tiempo real es valioso para:

- **Empresas:** Saber qué opinan los clientes sobre sus productos.
- **Investigadores:** Estudiar el comportamiento emocional de poblaciones.
- **Gobiernos:** Detectar tendencias de opinión pública.
- **Personas:** Comprender mejor el tono emocional de las conversaciones.

Sin embargo, analizar millones de tweets manualmente es imposible. Aquí es donde la Inteligencia Artificial se convierte en la herramienta perfecta.

## Solución

**Vibe Check IA** es una aplicación web local que:

1. **Lee** un dataset de tweets en español clasificados por sentimiento.
2. **Usa la API de Google Gemini** (un modelo de IA) para analizar y confirmar el sentimiento de cada tweet.
3. **Muestra gráficos interactivos** (pastel, barras y línea de tiempo) en un dashboard visual.
4. **Permite filtrar** tweets por tipo de sentimiento para un análisis más detallado.

## ¿Quién usa este proyecto?

| Usuario | ¿Para qué lo usa? |
|---------|-------------------|
| Estudiantes de programación | Aprender análisis de sentimientos con IA |
| Investigadores sociales | Analizar tendencias emocionales en Twitter |
| Emprendedores | Monitorear la opinión pública sobre su marca |
| Docentes | Enseñar conceptos de IA, datos y visualización |

## Valor del proyecto

- **Educativo:** Aprende Python, APIs de IA, visualización de datos y buenas prácticas de ingeniería de software.
- **Práctico:** Genera insights accionables a partir de datos reales de Twitter.
- **Ético:** Trabaja con datos públicos y respeta la privacidad de los usuarios.

## Dataset utilizado

**Twitter Sentiment Analysis in Spanish Tweets** de PhilipSanM en Kaggle:
https://www.kaggle.com/datasets/philipsanm/sentiment-analysis-in-spanish-tweets

Este dataset contiene tweets en español clasificados en 5 sentimientos y 20 emociones, lo que lo convierte en una fuente ideal para entrenar y evaluar modelos de análisis de sentimiento en español.
